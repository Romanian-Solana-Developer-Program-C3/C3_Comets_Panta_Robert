## Laboratory 5 ⚓
### Building Solana Programs with Anchor
In this section, we focus on building Solana smart contracts (programs) using Anchor, a framework that simplifies the development of on-chain applications. Anchor allows developers to write, test, and deploy smart contracts in a more secure and efficient way by handling many complexities under the hood.

### Commands 🛠️
- **Build the Program** 🚀
  ```sh
  anchor build
  ```

- **Run Unit Tests** 🧪
  ```sh
  anchor test  
  ```

Key Concepts
Anchor's Program Structure: Programs in Anchor are written in Rust, and they follow a specific structure that helps streamline the process. The program instructions (functions) are defined in a #[program] module.

Accounts: Anchor uses accounts as a way to store state. These accounts are either initialized or mutated by the program instructions, and they are typically backed by the Solana blockchain.

Program Derived Addresses (PDAs): These are special Solana addresses generated by the program itself, which allows users to interact with the program securely.

Example: Saving User Favorites
One example in this lab is a Solana program where users can store their favorite color, number, and hobbies on the blockchain. The program uses the Anchor framework to define and manage the program's state. The state is stored in an account, and only the owner of the account can modify the favorites data.
